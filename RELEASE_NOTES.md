Theoui's Trainers 1.0 — central launcher by Theoui.

- Automatically discovers installed game overlays in `/switch/TheouisTrainers/trainers/`.
- One launcher entry in Ultrahand; separate game downloads and updates.
- Refresh the trainer list, display embedded versions and use optional custom names.
- Migrate recognized old BL2/TOTK files and hide legacy entries while preserving other settings.

Copy **the contents of SD/** to the microSD root, then install the game trainers separately. This ZIP contains the launcher only. Launch/navigation on console remain to be validated.

Configurable current-game shortcut: six button presets plus Off, set in **Theoui's Trainers → Shortcut settings**. First-setup default: **L3 + R3** when free. Open the launcher once and return to Ultrahand to register it. Updated trainers support reopening and hand-off when the running game changes. Gameplay payloads and options are retained. Physical-console shortcut behaviour remains to be validated.
