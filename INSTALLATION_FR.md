# Theoui's Trainers 1.0 — installation

1. Installe au préalable Atmosphere, le chargeur d'overlays et Ultrahand.
2. Télécharge **TheouisTrainers_Loader_v1.0.zip** dans les Releases du dépôt du lanceur.
3. Copie **le contenu de SD/** à la racine de la microSD. Le fichier final doit être `/switch/.overlays/Trainers.ovl`.
4. Télécharge séparément BL2 et/ou TOTK, puis copie de la même manière le contenu de leur dossier SD/.
5. Ouvre **Theoui's Trainers** dans Ultrahand et choisis le jeu installé.

Les trainers vont dans `/switch/TheouisTrainers/trainers/`. Seul le lanceur est placé dans `.overlays`. **Refresh trainers** recharge la liste si tu viens d'ajouter un jeu.

Pour une mise à jour, remplace les fichiers du projet concerné. Il n'est pas nécessaire de réinstaller le lanceur à chaque mise à jour d'un jeu. Un fichier `.ini` facultatif, portant le même nom que le `.ovl`, personnalise son nom affiché.

Lors d'une mise à niveau depuis l'ancien pack, ouvre une fois le nouveau lanceur puis retourne dans Ultrahand pour actualiser la liste. Les copies anciennes conservées sont masquées ; les autres réglages restent présents.

## Raccourci configurable

Ouvre **Theoui's Trainers → Shortcut settings**, choisis un preset, puis **Return to Ultrahand**. Le raccourci ouvre le trainer du jeu actif. Voir **RACCOURCIS_FR.md** pour le premier réglage et les presets.
